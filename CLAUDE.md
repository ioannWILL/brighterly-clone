# Brighterly Project Context

## What is Brighterly?

**Online math and English learning school** for children in grades 1-9 (ages \~5-14).

* **Business model:** Curated tutoring marketplace with 1:1 online tutoring

* **Primary market:** United States

* **Subscription:** \~\$150-200/month for tutoring

## 2026 Strategic Goal

**Transform from tutoring product → learning platform** that creates value outside live tutor-led sessions.

### Key Objectives

* Release self-learning platform features

* Move educational value from lessons to platform itself

* Target: 30%+ of active users engaging with self-learning features

* Enable product-driven growth (scale without proportional supply/support growth)

### Constraints

* Tutoring remains core — new features must **complement**, not replace

* Self-learning section should deliver **standalone value** too

* Focus on **lean, quick releases** — no over-engineering

## COPPA Compliance

**Critical:** Mixed age range (5-14) means under-13 users are present.

* All external notifications → **parents only**

* No direct communications to children outside platform

* In-platform engagement for kids (badges, streaks, progress)

***

## Working on This Project

### Priorities

1. **Lean MVPs** — light or no-code approaches preferred
2. **Complement tutoring** — features should drive session prep, not replace sessions
3. **Parent-first notifications** — COPPA compliance is non-negotiable
4. **Measurable impact** — tie features to clear metrics
